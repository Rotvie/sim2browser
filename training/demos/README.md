# Grasp demonstrations

Training data for the learned grasp (004). Hand demonstrations recorded in the browser
(`?record`) are committed here as `hand.demos.jsonl.gz`: they are human data and cannot be
regenerated. Scripted demonstrations are regenerated with `npm run demos --workspace web` and are
gitignored. The file format is in
[`specs/004-learned-grasping/contracts/demo-file.md`](../../specs/004-learned-grasping/contracts/demo-file.md).
